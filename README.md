# Proyecto Master Data Science

Este repositorio reúne los proyectos individuales y grupales desarrollados durante el programa de Data Science. Aquí encontrarás trabajos analíticos aplicados a diferentes áreas, con un enfoque especial en:

- Técnicas de visualización y análisis en Power BI
- Cálculo e interpretación de métricas clave
- Proyectos de análisis de datos y modelización

## Contenido

- Proyectos individuales
- Trabajos colaborativos
- Ejemplos de dashboards y reportes
- Documentación de técnicas y resultados

## Objetivo

Presentar de forma organizada los proyectos realizados durante la formación, destacando los procesos, métodos y resultados obtenidos en cada trabajo.

## Cómo usar este repositorio

1. Explora las carpetas del proyecto para localizar cada trabajo.
2. Revisa la documentación y los informes asociados.
3. Usa los archivos como referencia para tus propios análisis y presentaciones.

---

Si deseas más detalles sobre algún proyecto específico, puedes consultar los documentos y archivos dentro de cada carpeta.
